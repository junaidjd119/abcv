1. Preconnect Issues

1.1 Duplicate Preconnects (gym-empire-arcade.html)

File gym-empire-arcade.html has duplicate preconnect tags for cdnjs.cloudflare.com and fonts.googleapis.com:

#LinePreconnect URLIssue

Impact: Duplicate preconnects waste connection slots; query params in preconnect URL cause the preconnect to fail silently.

1.2 Preconnect URL Format Issues (all pages)

All 107 pages with preconnect have fonts.googleapis.com&display=swap as the preconnect href. Two problems:

  • WRONG URL Preconnect should target the origin only: https://fonts.googleapis.com — not include &display=swap query parameter
  • HTML ENTITY & is an HTML entity — while browsers decode it to &, the resulting URL https://fonts.googleapis.com&display=swap is still malformed for preconnect
