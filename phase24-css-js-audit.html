11. No-Change Recommendations (GitHub Pages Constraints)

  • No custom server configuration: Cannot set Cache-Control headers, Gzip/Brotli levels, or enable HTTP/2 server push
  • No service worker: GitHub Pages does not support Service Workers for offline caching
  • No CDN customization: Fastly CDN is managed by GitHub — no control over edge caching
  • Largest savings require CSS tree-shaking: Tailwind purge + Font Awesome subsetting would save ~110 KB but require build tooling
  • Image optimization is the biggest opportunity — converting the 134 JPGs to WebP would save ~1-2 MB per page. This is a separate phase
